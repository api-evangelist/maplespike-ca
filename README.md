MapleSpike is an open‑source, self‑sovereign infrastructure platform that builds Canada’s public record data stack. It offers four products – Quill, Mosaic, Relay, and Helix – all forkable, verifiable, and self‑hostable under permissive licenses (AGPL‑3.0 / MIT). The platform is free to use, zero‑telemetry, and designed for transparency, privacy, and community governance, supporting developers, governments, and NGOs in managing public data responsibly.

**Areas:** OpenSource · DataInfrastructure · Canada · PublicRecord · SelfSovereign

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for MapleSpike: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
